# Whisper App 1.7.1

## Что изменилось

- Добавлен независимый выбор микрофона и устройства системного звука.
- Системный звук захватывается с точного Windows WASAPI render endpoint.
- Исправлен ложный отказ захвата во время тишины с помощью PCM heartbeat.
- Добавлены индикаторы уровня, health‑состояние, ручной повтор и переход к выбору устройства.
- Отключён незаметный переход на другое устройство; Windows default доступен как явный аварийный режим.
- Восстановлена автономная сборка renderer, native helper и NSIS‑установщика.

## Установка

Скачайте `Whisper-Setup-1.7.1-audio-devices.exe` из Assets и запустите его. Установщик предназначен для Windows x64.

Установщик не подписан Authenticode‑сертификатом, поэтому SmartScreen может показать предупреждение о неизвестном издателе. Контрольная сумма SHA‑256 публикуется после финальной сборки в описании релиза.
